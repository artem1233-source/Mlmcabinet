## 📊 Flow диаграммы

```
                          Добавить комментарий

                                  │
                          Нажать "Подтвердить"
                                  │
                          ┌───────┴────────┐
                          │                │
                     [Approve]        [Reject]

                          │           Статус: Rejected
                          │                │

                          Toast уведомление
                                   │
                            Обновление UI
                                   │
                               ✅ END
```
