# 🚀 Быстрый тест системы выводов

## ⚡ За 2 минуты проверим всю систему

### 1️⃣ Подготовка (30 секунд)

**Войдите как админ:**
- Email: `admin@admin.com` (или ваш admin email)
- Или пользователь с ID = "1" или "ceo"

**Проверьте баланс партнёра:**
- Нужен партнёр с балансом >= ₽1,000
- Если нет - начислите вручную через админ-панель

---

### 2️⃣ Создание заявки (30 секунд)

**От имени партнёра:**

1. Перейдите: **Баланс** (или **Balance**)
2. Нажмите: **"Создать заявку на вывод"**
3. Заполните:
   - ✅ Способ: **USDT (TRC-20)**
   - ✅ Сумма: **5000**
   - ✅ Адрес: **TExample123456789**
4. Нажмите: **"Подтвердить вывод"**

**Проверьте:**
- ✅ Баланс уменьшился на 5000
- ✅ Появилась заявка в истории со статусом 🟡 **"Ожидание"**

---

### 3️⃣ Обработка заявки - Одобрение (30 секунд)

**От имени администратора:**

1. Перейдите: **Финансы** (или **Finance**)
2. Увидите:
   - 📊 KPI карточка **"К выплате"** - красная с суммой ₽5,000
   - 🔔 Блок **"Заявки на выплату (1)"**
3. Нажмите: **"✅ Выплачено"**
4. В диалоге:
   - Введите: **"Выплачено 11.12.2024"**
   - Нажмите: **"Подтвердить"**

**Проверьте:**
- ✅ Заявка исчезла из pending
- ✅ Появилась в **"История операций"** со статусом 🟢 **"Выплачено"**
- ✅ Карточка "К выплате" стала белой с ₽0

---

### 4️⃣ Обработка заявки - Отклонение (30 секунд)

**Создайте ещё одну заявку** (повторите шаг 2)

**От имени администратора:**

1. В разделе **Финансы**
2. Нажмите: **"❌ Вернуть"**
3. В диалоге:
   - Введите: **"Неверные реквизиты"**
   - Нажмите: **"Отклонить"**

**Проверьте:**
- ✅ Заявка появилась в истории со статусом 🔴 **"Отклонено"**
- ✅ Средства вернулись на баланс пользователя (+5000)

---

## 📊 Проверка статистики

**В разделе Финансы смотрим 4 карточки:**

### 1. 💰 Оборот компании
- Сумма всех выполненных заказов
- Пример: ₽150,000

### 2. 👥 Баланс партнёров
- Сумма балансов всех пользователей
- Долг системы
- Пример: ₽45,000

### 3. ⚠️ К выплате
- Сумма pending заявок
- **Красная**, если > 0
- Показывает количество заявок
- Пример: ₽15,000 (3 заявки)

### 4. 💵 Чистая прибыль
- Оборот минус начисления
- Может быть отрицательной
- Пример: ₽105,000

**При создании заявки увидите:**
```
💸 Withdrawal requested: ₽5000 by Иван (ID: 1702384920123)
```

**При обработке администратором:**
```
💸 Sending payout action: {withdrawalId: "1702384920123", action: "approve", ...}
💸 Payout action response: {success: true, message: "Выплата подтверждена"}
```

**При возврате средств:**
```
💰 Returned ₽5000 to user 012 (balance: ₽10000 → ₽15000)
```

### Проверка ограничений

**Минимальная сумма:**
- Попробуйте вывести ₽500
- Должна быть ошибка: "Минимальная сумма вывода: ₽1,000"

**Недостаточно средств:**
- Попробуйте вывести больше баланса
- Должна быть ошибка: "Недостаточно средств"
