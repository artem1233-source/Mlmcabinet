# ✅ Руководство по тестированию URL синхронизации модулей

## Быстрый тест

### Предварительные условия
1. Убедитесь, что вы вошли в систему как CEO/Owner
2. Откройте консоль браузера (F12) для просмотра логов

### Тест 1: Загрузка с параметром URL

**Шаги:**
1. Откройте приложение с URL: `/?module=finance`
2. Убедитесь, что открыт модуль "Финансы"
3. В консоли должен быть лог: `🔗 Loading module from URL: finance`

**Ожидаемый результат:**
- Вкладка "Финансы" активна (зеленая)
- Отображается контент финансового дашборда
- URL содержит `?module=finance`

### Тест 2: Переключение между модулями

**Шаги:**
1. Находясь на любом модуле, кликните на вкладку "Склад"
2. Проверьте URL в адресной строке
3. В консоли должен быть лог: `🔗 Updated URL: /?module=warehouse`

**Ожидаемый результат:**
- Вкладка "Склад" становится активной (оранжевая)
- URL обновляется на `?module=warehouse`
- Контент меняется на складской дашборд
- Страница НЕ перезагружается

### Тест 3: Переключение всех модулей

Последовательно кликните на каждую вкладку и проверьте URL:

| Вкладка | Ожидаемый URL | Цвет вкладки |
|---------|---------------|--------------|
| Центр управления | `?module=ceo` | Фиолетовый (#8B5CF6) |
| Администрирование | `?module=admin` | Голубой (#39B7FF) |
| Финансы | `?module=finance` | Зеленый (#10B981) |
| Склад | `?module=warehouse` | Оранжевый (#F59E0B) |
| SEO / Маркетинг | `?module=seo` | Розовый (#EC4899) |
| Поддержка | `?module=support` | Индиго (#6366F1) |
| Партнёр | `?module=partner` | Голубой (#39B7FF) |

### Тест 4: Прямые ссылки

Попробуйте открыть следующие URL в новой вкладке:

```
/?module=ceo
/?module=admin
/?module=finance
/?module=warehouse
/?module=seo
/?module=support
/?module=partner
```

**Ожидаемый результат:**
Каждая ссылка открывает соответствующий модуль

### Тест 5: Невалидный модуль

**Шаги:**
1. Откройте URL: `/?module=invalid`
2. Проверьте какой модуль открылся

**Ожидаемый результат:**
- Открыт модуль "Центр управления" (дефолтный)
- URL остается `?module=invalid` (или перезаписывается на `?module=ceo` при первом клике)

### Тест 6: Работа только для CEO

**Шаги:**
1. Переключитесь на роль "Партнёр" через TopBarRu
2. Проверьте URL
3. Попробуйте переключить разделы

**Ожидаемый результат:**
- URL НЕ содержит `?module=`
- Модульные вкладки НЕ отображаются
- Синхронизация URL отключена

## Консольные логи

При правильной работе вы должны видеть:

```javascript
// При загрузке из URL
🔗 Loading module from URL: finance

// При клике на вкладку
🔗 Updated URL: /?module=warehouse

// Общие логи
🔥 UnifiedDashboard render: { currentRole: 'owner', mode: 'ceo', activeModule: 'finance' }
🎨 Rendering mode: ceo | effective: finance
```

## Известные ограничения

1. **История браузера**: Кнопки "Назад"/"Вперед" обновят URL, но НЕ обновят состояние модуля автоматически
   - **Решение**: Требуется добавить `popstate` listener (опциональная фича)

2. **Другие query параметры**: Если в URL есть другие параметры (например `?tab=orders&module=finance`), они сохраняются

## Debugging

Если что-то не работает:

1. **Проверьте роль**: Убедитесь что `currentRole === 'owner'` (или id === 'ceo')
2. **Проверьте mode**: В консоли должно быть `mode: 'ceo'`
3. **Проверьте URL**: Откройте DevTools → Network → Headers → Request URL
4. **Включите DEBUG_UI**: В `/components/dashboard/DashboardLayout.tsx` установите `const DEBUG_UI = true;`

## Дополнительные сценарии

```
Пользователь A (CEO) открывает модуль "Финансы"
URL: /?module=finance
Копирует ссылку и отправляет Пользователю B (CEO)
Пользователь B открывает ссылку → Видит модуль "Финансы"
```

```
Пользователь сохраняет в закладки: /?module=warehouse
При открытии закладки → Сразу открывается модуль "Склад"
```
