## 📝 Шаги тестирования

### 1. Выход из системы
```
1. Нажмите на профиль в верхнем меню
2. Выберите "Выход"
3. Убедитесь, что вы на странице входа

```

```
Пароль: [ваш пароль для пользователя 001]
```

Должны увидеть:
```

✅ Admin access granted for artem1233@mail.ru
✅ 🔐 requireAdmin check: userId=001, email=artem1233@mail.ru, isAdmin=true
```

НЕ должны видеть:
```

```

- [ ] В боковом меню есть пункт **"H2 Админ"** или **"H2 Platform"**

- [ ] Админ-панель загружается без ошибок

## 🚨 Если что-то не работает

### Ошибка: "Admin access denied"
**Решение:**
1. Очистите localStorage: `localStorage.clear()` в консоли
2. Выйдите и войдите снова
3. Проверьте, что email точно `artem1233@mail.ru` (без пробелов)

### Ошибка: Нет пункта "H2 Админ" в меню
**Решение:**
1. Проверьте консоль на наличие `[ADMIN]` в логах
2. Перезагрузите страницу (Ctrl+F5)
3. Проверьте, что сервер обновлён (deployment завершён)

### Ошибка: 500 Server Error
**Решение:**
1. Проверьте, что сервер запущен и работает
2. Проверьте логи сервера в Supabase Edge Functions
3. Убедитесь, что изменения в `/supabase/functions/server/index.tsx` задеплоены
