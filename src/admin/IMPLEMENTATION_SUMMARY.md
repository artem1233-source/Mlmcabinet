## 🎓 Как использовать

### Запуск тестирования:
```bash
1. Откройте H2 Admin через кнопку в sidebar (только для CEO)
2. Выберите раздел "Тестирование" в sidebar
3. Нажмите "Запустить тесты"
4. Дождитесь завершения (~30 секунд)
5. Проверьте результаты
```

### Переключение ролей:
```bash
1. Убедитесь, что вы в роли SEO/Owner
2. Нажмите на кнопку с текущей ролью в topbar (справа)
3. Выберите нужную роль из списка
4. Интерфейс автоматически адаптируется
```

### Экспорт данных:
```typescript
import { exportOrders, exportUsers } from '/admin/utils/exportUtils';

// Экспорт заказов
exportOrders(orders, 'SEO');

// Экспорт пользователей
exportUsers(users);
```

### Глобальный поиск:
```typescript
import { GlobalSearch } from '/admin/components/ui/GlobalSearch';

<GlobalSearch 
  searchScope="all"
  data={{ users, orders, payouts, products }}
  onResultClick={(result) => console.log(result)}
/>
```
