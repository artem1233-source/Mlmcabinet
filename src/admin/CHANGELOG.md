### ✨ Функциональность

#### Модульные вкладки (верхние табы)
- ✅ Автоматическое отображение только доступных модулей для роли
- ✅ Owner видит все 7 модулей
- ✅ Другие роли видят только свой модуль
- ✅ Скрытие вкладок если доступен только 1 модуль
- ✅ Визуальная индикация активного модуля

#### Автоматический редирект
- ✅ При смене роли → переход на домашний дашборд роли
- ✅ При попытке доступа к запрещенному разделу → toast-ошибка + блокировка
- ✅ Консольные логи для отладки (`🔄`, `🔀`, `📊`, `🎯`)

#### Матрица доступа
- ✅ SEO (Owner): все модули и разделы
- ✅ AdminOps: только модуль "Администрирование"
- ✅ Finance: только модуль "Финансы"
- ✅ Warehouse: только модуль "Склад"
- ✅ Marketing: только модуль "Маркетинг"
- ✅ Support: только модуль "Поддержка"
- ✅ Partner: только модуль "Партнёр"

#### Режим инспекции (Owner)
- ✅ Показывает все разделы с замочками на недоступных
- ✅ Блокирует клик на недоступные разделы
- ✅ Желтый баннер в сайдбаре
- ✅ Работает только для роли SEO (Owner)

#### Toast-уведомления
- ✅ Успешная смена роли: "Режим изменён: [Роль]"
- ✅ Попытка доступа к запрещенному разделу: "Раздел недоступен для текущей роли"
