# H2 Platform - Панель управления

## 🎯 Описание
Единая панель управления H2 Platform с системой ролей и переключением режимов.

## ✨ Новое: Система ролевого доступа

**Статус**: ✅ Полностью функционально (версия 1.0)

### Основные возможности
- ✅ **Модульные вкладки** - автоматически скрываются в зависимости от роли
- ✅ **Автоматический редирект** - переход на домашний дашборд при смене роли
- ✅ **Условная навигация** - левое меню показывает только доступные разделы
- ✅ **Режим инспекции** - для Owner, показывает все разделы с замочками на недоступных
- ✅ **Toast-уведомления** - при смене роли и ошибках доступа

## 👑 Роли

### 1. Владелец (Owner/SuperAdmin)
- **Код роли**: SEO
- **Доступ**: полный ко всем функциям
- **Особенности**: может переключаться между режимами других ролей
- **Разделы**: Центр управления, все остальные разделы

### 2. Администрирование (AdminOps)
- **Код роли**: AdminOps
- **Доступ**: управление партнёрами, PII данные
- **Функции**: блокировка, разблокировка, массовые операции

### 3. Финансы (Finance)
- **Код роли**: Finance
- **Доступ**: выплаты, возвраты, себестоимость
- **Функции**: approve/reject выплат, возвраты

### 4. Склад (Warehouse)
- **Код роли**: Warehouse
- **Доступ**: заказы к сборке, отправке
- **Функции**: управление статусами, трек-номера

### 5. Маркетинг (Marketing)
- **Код роли**: Marketing
- **Доступ**: источники, UTM, промокоды (без PII)
- **Функции**: аналитика, кампании

### 6. Поддержка (Support)
- **Код роли**: Support
- **Доступ**: тикеты, заказы клиентов
- **Функции**: инициирование возвратов

### 7. Партнёр (Partner)
- **Код роли**: Partner
- **Доступ**: свои заказы, начисления, команда
- **Функции**: запрос выплат, повтор заказов

## 🎨 Компоненты

### UI Components
- `KPICard` - карточки показателей (S/M/L)
- `AlertBanner` - баннеры уведомлений (critical/warning/info)
- `PeriodSelector` - переключатель периодов
- `AdminTopbar` - верхняя панель с поиском и действиями
- `AdminSidebar` - боковое меню навигации
- `ModuleTabs` - **НОВОЕ**: модульные вкладки с условной отрисовкой по ролям

### Layout
- `AdminDashboard` - главный контейнер
- Автоматическое переключение разделов при смене роли
- Адаптивный дизайн (desktop/mobile)

### Utils
- `roleAccess.ts` - **НОВОЕ**: централизованная система контроля доступа
  - Матрица доступа к модулям и разделам
  - Функции проверки прав доступа
  - Автоматический редирект при смене роли

## 🚀 Использование

### Доступ
Панель доступна только пользователям с ролью CEO:
- В sidebar появляется кнопка "H2 Admin" (с иконкой 👑)
- При клике открывается панель управления

### Переключение ролей
Только для роли SEO (Owner):
- В topbar справа кнопка с текущей ролью
- При клике открывается меню выбора роли
- После выбора роли интерфейс адаптируется автоматически

### Периоды
Глобальный переключатель в topbar:
- Сегодня
- 7 дней
- 30 дней
- 90 дней
- Год

### Поиск
Глобальный поиск в topbar с выбором области:
- Пользователи
- Заказы
- Выплаты
- Товары

## 🔐 Безопасность

### PII (Персональные данные)
- **Полный доступ**: Владелец, Администрирование, Склад, Поддержка
- **Ограниченный**: Маркетинг (только агрегаты)
- **Нет доступа**: Партнёр (только свои данные)

### Audit Log
- Хранится 24 месяца
- Доступен всем сотрудникам
- Партнёры видят только свои важные события
