## 🎯 Поведение системы

### При смене роли
1. ✅ Toast-уведомление "Режим изменён: [Роль]"
2. ✅ Автоматический переход на домашний дашборд роли
3. ✅ Обновление модульных вкладок (скрытие недоступных)
4. ✅ Обновление левого меню (фильтрация разделов)
5. ✅ Консольный лог `🔄 Role changing from X to Y`

### При попытке доступа к запрещенному разделу
1. ✅ Toast-уведомление "Раздел недоступен для текущей роли"
2. ✅ Блокировка перехода
3. ✅ Пользователь остается на текущем разделе

### В режиме инспекции (Owner)
1. ✅ Отображаются все разделы в левом меню
2. ✅ Недоступные помечены замочком 🔒
3. ✅ Клик на недоступные заблокирован
4. ✅ Желтый баннер с пояснением в сайдбаре

## 🧪 Как протестировать

### Быстрый тест (1 минута)
1. Откройте H2 Admin (кнопка в сайдбаре)
2. Кликните на кнопку с ролью в правом верхнем углу
3. Выберите "Финансы"
4. ✅ Проверьте: только вкладка "💰 Финансы" сверху
5. ✅ Проверьте: левое меню показывает только Финансы, Заказы, Аналитика, Настройки
6. ✅ Проверьте: дашборд показывает FinanceDashboard

### Полный тест (5 минут)
1. Откройте консоль браузера (F12)
2. Переключайтесь между всеми 7 ролями
3. Для каждой роли проверьте:
   - Модульные вкладки отображаются корректно
   - Левое меню фильтруется
   - Дашборд соответствует роли
   - Консольные логи выводятся

### Автоматический тест
1. Перейдите в раздел "Тестирование" (доступен только Owner)
2. Кликните "Запустить тесты"
3. ✅ Наблюдайте автоматическую проверку всех ролей и разделов
