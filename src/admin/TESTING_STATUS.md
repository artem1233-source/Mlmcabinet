## 🎯 Рекомендации для тестирования

### Как запустить тесты:
1. Откройте H2 Admin через кнопку в sidebar (только для CEO)
2. Убедитесь, что вы в роли SEO/Owner
3. В sidebar выберите раздел "Тестирование"
4. Нажмите кнопку "Запустить тесты"
5. Дождитесь завершения (около 30 секунд)
6. Проверьте результаты

### Ручное тестирование:
1. **Переключение ролей**: Нажмите на кнопку с текущей ролью в topbar
2. **Инспекция доступов**: Включите переключатель в меню ролей
3. **Навигация**: Проверьте доступные разделы для каждой роли
4. **Фильтры**: Используйте фильтры на каждом дашборде
5. **Поиск**: Проверьте поиск по пользователям/заказам
6. **Массовые операции**: Выберите несколько элементов и примените действие
