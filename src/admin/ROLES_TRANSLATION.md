# ✅ Перевод ролей на русский язык

## 📋 Что сделано

Все роли в админ-панели H2 Platform переведены на русский язык с сохранением английских эквивалентов для понятности и технической документации.

## 🎯 Таблица соответствия ролей

| Код роли (техническое название) | Русское название | Английское название |
|--------------------------------|------------------|-------------------|
| `SEO` | Владелец | Owner/SuperAdmin |
| `AdminOps` | Администрирование | AdminOps |
| `Finance` | Финансы | Finance |
| `Warehouse` | Склад | Warehouse |
| `Marketing` | Маркетинг | Marketing |
| `Support` | Поддержка | Support |
| `Partner` | Партнёр | Partner |

**Статус**: Не требуют изменений

Технические названия компонентов (например, `AdminOpsDashboard`, `FinanceDashboard`) остаются на английском языке, так как это соответствует стандартам именования в React. Русские названия отображаются в пользовательском интерфейсе через `ROLE_CONFIGS[role].name`.

## 🎨 Отображение в интерфейсе

### AdminTopbar
- Отображает русское название текущей роли из `ROLE_CONFIGS[currentRole].name`
- В меню переключения ролей показываются русские названия и описания

### AdminSidebar
- Labels навигационных элементов уже на русском языке
- Привязка к ролям использует технические коды (`'SEO'`, `'AdminOps'` и т.д.)

### Toast-уведомления
```typescript
toast.success(`Режим изменён: ${ROLE_CONFIGS[role].name}`);
// Пример: "Режим изменён: Финансы"
```

## 🔍 Проверка консистентности

### ✅ Все русские названия используются в:
- Топбар (выбор роли, отображение текущей роли)
- Toast-уведомления при смене роли
- README.md (документация)
- Описания иконок

### ✅ Технические коды остаются неизменными:
- TypeScript типы (`type Role = 'SEO' | 'AdminOps' | ...`)
- Названия компонентов (`AdminOpsDashboard.tsx`, `FinanceDashboard.tsx`)
- Условия в коде (`if (role === 'SEO')`)
- Массивы ролей в правах доступа (`roles: ['SEO', 'Finance']`)

## 📝 Принципы перевода

1. **Русское название с английским в скобках** для роли Owner/SuperAdmin:
   - "Владелец (Owner/SuperAdmin)"
   - Показывает техническую природу роли

2. **Только русское название** для остальных ролей:
   - "Администрирование", "Финансы", "Склад" и т.д.
   - Более чистый и понятный интерфейс

3. **Технические названия без изменений**:
   - Код роли: `'SEO'`, `'AdminOps'`, `'Finance'` и т.д.
   - Имена компонентов: `AdminOpsDashboard`, `FinanceDashboard` и т.д.
   - Поддержка читабельности кода и стандартов React
