## 🚀 Быстрый старт - 3 пути

### Путь 1: Интерактивное тестирование (РЕКОМЕНДУЕТСЯ) ⭐

**Время**: 10-15 минут  
**Для кого**: Все

```
1. Откройте приложение
2. Войдите как `seo`
3. Нажмите "H2 Admin" в меню
4. Перейдите в раздел "Тестирование" (🧪)
5. Следуйте инструкциям в интерактивной панели
6. Нажмите "Сгенерировать отчёт"
```

**Результат**: Автоматический отчёт о готовности + рекомендация по заказам

---

### Путь 2: Ручное тестирование по протоколу

**Время**: 30-45 минут  
**Для кого**: Тестировщики, PM

```
1. Откройте /admin/ТЕСТ_ПРОТОКОЛ.md
2. Распечатайте или откройте в отдельном окне
3. Выполняйте тесты по чеклисту
4. Заполняйте таблицы оценок
5. Записывайте баги
```

**Результат**: Детальный анализ всех функций

---

### Путь 3: Только выбор заказов

**Время**: 5-10 минут  
**Для кого**: Те, кто уже знает что админка работает

```
1. Откройте /admin/БЫСТРЫЙ_ВЫБОР_ЗАКАЗОВ.md
2. Следуйте инструкциям
3. Протестируйте 5 вариантов
4. Примите решение
```

**Результат**: Выбран финальный вариант экрана заказов

## ⚡ Быстрые команды

### Открыть интерактивное тестирование
```
H2 Admin → Тестирование (🧪)
```

### Посмотреть варианты заказов
```
Партнёрский кабинет → Заказы → Кнопки вверху экрана
```

### Переключить роль
```
Админка → Правый верхний угол → Кнопка роли
```

### Включить режим инспекции
```
Меню роли → Переключатель "Показать все разделы"
```
