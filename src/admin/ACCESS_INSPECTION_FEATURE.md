# Функция "Инспекция доступов"

## Описание
Режим инспекции доступов позволяет супер-администратору (роль SEO/Owner) видеть все пункты меню системы H2 Platform, включая те, к которым у текущей выбранной роли нет доступа.

## Расположение
Функция находится в выпадающем меню переключения ролей в верхней панели (AdminTopbar):
- Кнопка переключения ролей (правый верхний угол)
- Выпадающее меню "Выбор роли"
- В нижней части меню, после разделителя: переключатель "Инспекция доступов"

## Как это работает

### 1. Включение режима
- Откройте меню переключения ролей (клик по кнопке с текущей ролью)
- Найдите переключатель "Инспекция доступов" внизу меню
- Активируйте переключатель

### 2. Визуальные индикаторы

#### В боковой панели (Sidebar):
- **Баннер режима инспекции**: Появляется под логотипом, информирует о включенном режиме
- **Доступные пункты**: Отображаются обычным образом, кликабельны
- **Недоступные пункты**: 
  - Серый цвет текста и иконки
  - Серый фон
  - Сниженная прозрачность (opacity: 60%)
  - Иконка замка 🔒 справа
  - Курсор `not-allowed`
  - Не реагируют на клики

#### В топбаре:
- Нет визуальных изменений, кроме состояния переключателя

### 3. Функциональность по ролям

| Роль | Может видеть | Может использовать инспекцию |
|------|-------------|------------------------------|
| SEO (Owner) | Все разделы | ✅ Да |
| AdminOps | Админ, Заказы, Аналитика | ❌ Нет |
| Finance | Финансы, Заказы, Аналитика | ❌ Нет |
| Warehouse | Склад, Заказы | ❌ Нет |
| Marketing | Маркетинг, Аналитика | ❌ Нет |
| Support | Поддержка, Заказы | ❌ Нет |
| Partner | Заказы | ❌ Нет |

## Сценарии использования

### Сценарий 1: Проверка доступов роли Finance
1. Владелец входит в режим SEO (по умолчанию)
2. Переключается на роль Finance
3. Включает "Инспекцию доступов"
4. Видит все разделы:
   - ✅ Финансы (доступно)
   - ✅ Заказы (доступно)
   - ✅ Аналитика (доступно)
   - 🔒 Центр управления (заблокировано)
   - 🔒 Администрирование (заблокировано)
   - 🔒 Склад (заблокировано)
   - 🔒 Маркетинг (заблокировано)
   - 🔒 Поддержка (заблокировано)
   - 🔒 Партнёр (заблокировано)

### Сценарий 2: Отладка прав доступа
- Владелец может быстро проверить, какие разделы видны для каждой роли
- Не нужно выходить и входить под разными пользователями
- Удобно для демонстрации клиентам или команде

## Техническая реализация

### Изменённые файлы
1. `/admin/components/layout/AdminTopbar.tsx`
   - Добавлен переключатель "Инспекция доступов"
   - Добавлены props: `showAccessInspection`, `onAccessInspectionChange`
   - Добавлен обработчик закрытия меню при клике вне

2. `/admin/components/layout/AdminSidebar.tsx`
   - Добавлен prop: `showAccessInspection`
   - Логика отображения всех разделов в режиме инспекции
   - Визуальная индикация заблокированных пунктов
   - Информационный баннер режима

3. `/admin/AdminDashboard.tsx`
   - Добавлен state: `showAccessInspection`
   - Прокидывание state в дочерние компоненты

### Состояние
```typescript
const [showAccessInspection, setShowAccessInspection] = useState(false);
```

### Логика фильтрации
```typescript
const visibleSections = showAccessInspection 
  ? allSections  // Показать все
  : allSections.filter(section => section.roles.includes(currentRole));  // Только доступные
```

### Логика блокировки
```typescript
const hasAccess = section.roles.includes(currentRole);
const isLocked = showAccessInspection && !hasAccess;

onClick={() => hasAccess ? onSectionChange(section.id) : null}
disabled={isLocked}
```
