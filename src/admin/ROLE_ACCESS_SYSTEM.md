# Система ролевого доступа H2 Platform

## 🎯 Обзор

Полностью функциональная система контроля доступа по ролям с автоматическим редиректом и условной отрисовкой модулей.

## ✨ Возможности

### 1. **Модульные вкладки (верхние табы)**
- Автоматически скрываются в зависимости от роли
- Владелец видит ВСЕ модули
- Другие роли видят только свой модуль

### 2. **Автоматический редирект**
- При смене роли → автоматический переход на домашний дашборд роли
- При попытке доступа к запрещенному разделу → toast-уведомление + блокировка

### 3. **Левое меню (sidebar)**
- Показывает только доступные разделы
- Режим инспекции (только для Owner) - показывает все разделы с замочками

## 🏠 Домашние дашборды

При выборе роли пользователь попадает на соответствующий дашборд:

- **Owner/SEO** → `OwnerDashboard`
- **Администрирование** → `AdminOpsDashboard`
- **Финансы** → `FinanceDashboard`
- **Склад** → `WarehouseDashboard`
- **Маркетинг** → `MarketingDashboard`
- **Поддержка** → `SupportDashboard`
- **Партнёр** → `PartnerDashboard`

### Ключевые функции в `roleAccess.ts`

```typescript
// Проверка доступа к модулю
hasModuleAccess(role: Role, module: Module): boolean

// Проверка доступа к разделу
hasSectionAccess(role: Role, section: Section): boolean

// Получить доступные модули для роли
getAvailableModules(role: Role): Module[]

// Получить домашний дашборд для роли
getHomeDashboard(role: Role): Section

// Проверить необходимость редиректа
getRedirectSection(role: Role, currentSection: Section): Section | null
```

## 🎮 Как использовать

### Для пользователя

1. **Смена роли**: 
   - Кликнуть на кнопку с текущей ролью в правом верхнем углу
   - Выбрать нужную роль из списка
   - Система автоматически переключит интерфейс

2. **Навигация**:
   - **Верхние вкладки** - переключение между модулями (если доступно несколько)
   - **Левое меню** - навигация внутри модуля

3. **Режим инспекции** (только Owner):
   - Включить переключатель "Инспекция доступов" в меню ролей
   - Увидеть все разделы с замочками на недоступных

### Для разработчика

#### Добавить новый модуль

1. Добавить тип модуля в `roleAccess.ts`:
```typescript
export type Module = 
  | 'control'
  | 'admin'
  | 'my_new_module'; // Новый модуль
```

2. Обновить матрицу доступа:
```typescript
const MODULE_ACCESS: Record<Role, Module[]> = {
  SEO: ['control', 'admin', 'my_new_module'],
  MyRole: ['my_new_module'],
  // ...
};
```

3. Добавить конфигурацию:
```typescript
export const MODULE_CONFIGS: Record<Module, ModuleConfig> = {
  my_new_module: {
    id: 'my_new_module',
    label: 'Мой модуль',
    section: 'my_section',
    icon: '🚀'
  }
};
```

#### Добавить новый раздел

1. Добавить тип раздела в `roleAccess.ts`:
```typescript
export type Section = 
  | 'dashboard'
  | 'my_new_section'; // Новый раздел
```

2. Обновить матрицу доступа:
```typescript
const SECTION_ACCESS: Record<Role, Section[]> = {
  SEO: ['dashboard', 'my_new_section'],
  // ...
};
```

3. Добавить рендеринг в `AdminDashboard.tsx`:
```typescript
switch (activeSection) {
  case 'my_new_section':
    return <MyNewSectionComponent />;
  // ...
}
```

```

🎯 Rendering dashboard for role: Finance
```

- ✅ Успешная смена роли: "Режим изменён: [Название роли]"
- ❌ Попытка доступа к запрещенному разделу: "Раздел недоступен для текущей роли"
- ℹ️ Обновление данных: "Данные обновлены"

## 🎨 UI/UX особенности

### Модульные вкладки
- Отображаются только если доступно 2+ модулей
- Активная вкладка: синий цвет (#39B7FF) + нижняя граница
- Неактивная вкладка: серый цвет (#666) + hover эффект

### Переключатель ролей (Owner)
- Градиентный фон (purple-50 → blue-50)
- Иконка роли + название
- Выпадающее меню с карточками ролей
- Цветные иконки для каждой роли
- Индикатор текущей роли (синяя точка)

### Режим инспекции (Owner)
- Желтый баннер в сайдбаре
- Замочки на недоступных пунктах
- Блокировка клика на недоступных пунктах
