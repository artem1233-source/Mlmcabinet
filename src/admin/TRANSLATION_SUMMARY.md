## 🔧 Технические детали

### Что НЕ изменилось (и это правильно)

1. **TypeScript типы**
   ```typescript
   export type Role = 'SEO' | 'AdminOps' | 'Finance' | 'Warehouse' | 'Marketing' | 'Support' | 'Partner';
   ```
   Остались на английском для консистентности кода

2. **Названия компонентов**
   - `AdminOpsDashboard.tsx` (не `АдминистрированиеДашборд.tsx`)
   - `FinanceDashboard.tsx` (не `ФинансыДашборд.tsx`)
   - Соответствует стандартам React и читабельности кода

3. **Условия в коде**
   ```typescript
   if (role === 'SEO')
   else if (role === 'AdminOps')
   ```
   Используют технические коды для надёжности

4. **Массивы прав доступа**
   ```typescript
   roles: ['SEO', 'AdminOps', 'Finance']
   ```
   Технические коды для логики приложения

## 🌟 Особенности перевода

### Owner/SuperAdmin
- **Формат**: "Владелец (Owner/SuperAdmin)"
- **Причина**: Показывает техническую природу суперадминистратора
- **Где используется**: Везде в UI и документации

### Остальные роли
- **Формат**: Только русское название без скобок
- **Примеры**: "Администрирование", "Финансы", "Склад"
- **Причина**: Более чистый и понятный интерфейс
