# 🔍 Инспекция доступов — Краткая инструкция

## Что это?
Режим для просмотра ВСЕХ разделов панели управления, включая недоступные для текущей роли.

## Где найти?
```
Панель H2 Platform → Кнопка роли (правый верхний угол) → Инспекция доступов ⬇️
```

## Как включить?
1. Кликните на кнопку с текущей ролью (например, "👑 Владелец")
2. Прокрутите меню вниз
3. Включите переключатель "Инспекция доступов"

## Что произойдёт?

### ✅ В боковом меню появится:
```
┌─────────────────────────────────┐
│ 🔒 Режим инспекции              │
│ Показаны все разделы.           │
│ Заблокированные недоступны...   │
└─────────────────────────────────┘
```

### ✅ Доступные пункты:
- ✅ Финансы ← Можно кликнуть
- ✅ Заказы ← Можно кликнуть

### 🔒 Недоступные пункты:
- 🔒 Администрирование 🔒 ← Серый, заблокирован
- 🔒 Склад 🔒 ← Серый, заблокирован
- 🔒 Маркетинг 🔒 ← Серый, заблокирован

## Пример использования

### Проверить доступы роли "Финансы":
```
1. Переключиться на роль "Finance"
2. Включить инспекцию
3. Увидеть: 
   ✅ Финансы
   ✅ Заказы
   ✅ Аналитика
   🔒 Остальные разделы (7 шт)
```

### Проверить доступы роли "Поддержка":
```
1. Переключиться на роль "Support"
2. Включить инспекцию
3. Увидеть:
   ✅ Поддержка
   ✅ Заказы
   🔒 Остальные разделы (8 шт)
```

## Важно! ⚠️
- Функция доступна ТОЛЬКО для роли **Владелец (SEO/Owner)**
- Заблокированные пункты НЕ открываются при клике
- Режим сохраняется до отключения переключателя
- Автоматически закрывается при клике вне меню

## Зачем нужно?
✅ Быстрая проверка прав доступа  
✅ Отладка без создания тестовых пользователей  
✅ Демонстрация системы ролей клиентам  
✅ Планирование распределения задач в команде
