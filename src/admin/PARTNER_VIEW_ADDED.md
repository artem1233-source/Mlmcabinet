# ✅ Добавлена вкладка "Партнёр" в админ-панель

## 📋 Что сделано

В главный тулбар админ-панели H2 Platform добавлена новая вкладка **"Партнёр"**, которая позволяет владельцу (SEO/SuperAdmin) видеть партнерский дашборд таким, каким его видят обычные партнёры.

## 🎯 Возможности

### 1. Новая вкладка в сайдбаре
- **Название**: Партнёр
- **Иконка**: UserCheck (✓)
- **Доступ**: Только для роли SEO (Owner/SuperAdmin)
- **Позиция**: После вкладки "Поддержка", перед "Заказы"

### 2. Режим просмотра партнерского интерфейса
Когда владелец переходит на вкладку "Партнёр", он видит:

- **Информационный баннер** с пояснением режима просмотра
- **Полный партнерский дашборд** с демо-данными, включающий:
  - Приветственный блок с реферальными ссылками
  - KPI-карточки (доход, команда, баланс, заказы)
  - Виджет целей
  - Прогресс до следующего уровня
  - Графики дохода и структуры команды
  - Топ товары по продажам

### 3. Демо-данные
Для демонстрации используется виртуальный партнёр:
```javascript
{
  id: 'demo_partner',
  email: 'partner@demo.com',
  full_name: 'Демо Партнёр',
  ref_code: 'DEMO123',
  rank: 2,
  balance: 25000
}
```

## 🔄 Навигация

### Как использовать:
1. Войдите в админ-панель H2 Platform
2. В левом сайдбаре найдите вкладку **"Партнёр"** (с иконкой ✓)
3. Кликните на неё
4. Вы увидите информационный баннер и полный партнерский дашборд

### Быстрый доступ:
- Вкладка "Партнёр" находится в главном меню навигации
- Доступна только для роли SEO (Owner/SuperAdmin)
- При переключении ролей через верхний тулбар эта вкладка остаётся доступной только для SEO

## 🎯 Преимущества

1. **Быстрый просмотр** - Владелец может мгновенно увидеть партнерский интерфейс без переключения аккаунтов
2. **Тестирование UX** - Легко проверить, как выглядит интерфейс для партнёров
3. **Демонстрация** - Удобно показывать потенциальным партнёрам их будущий кабинет
4. **Контроль качества** - Владелец всегда в курсе, какой опыт получают партнёры
