# 🚀 Быстрый гайд по переключению ролей

## Как протестировать систему ролей

### 1. Откройте H2 Admin
Кликните на кнопку **"H2 Admin"** в сайдбаре партнерского кабинета (доступна только CEO).

### 2. Переключите роль
1. В правом верхнем углу найдите кнопку с текущей ролью (по умолчанию "👑 Владелец (Owner/SuperAdmin)")
2. Кликните на неё
3. В выпадающем меню выберите роль для тестирования

### 3. Что произойдёт после переключения

#### ✅ **Owner/SEO** (по умолчанию)
- **Верхние вкладки**: Все 7 модулей
- **Левое меню**: Все разделы + Тестирование
- **Дашборд**: OwnerDashboard с полной аналитикой

#### 💼 **Администрирование**
- **Верхние вкладки**: Только "⚙️ Администрирование"
- **Левое меню**: Администрирование, Заказы, Аналитика, Настройки
- **Дашборд**: AdminOpsDashboard (управление партнерами)

#### 💰 **Финансы**
- **Верхние вкладки**: Только "💰 Финансы"
- **Левое меню**: Финансы, Заказы, Аналитика, Настройки
- **Дашборд**: FinanceDashboard (выплаты, возвраты)

#### 📦 **Склад**
- **Верхние вкладки**: Только "📦 Склад"
- **Левое меню**: Склад, Заказы, Настройки
- **Дашборд**: WarehouseDashboard (сборка, отгрузка)

#### 📊 **Маркетинг**
- **Верхние вкладки**: Только "📊 SEO / Маркетинг"
- **Левое меню**: Маркетинг, Аналитика, Настройки
- **Дашборд**: MarketingDashboard (источники, UTM)

#### 💬 **Поддержка**
- **Верхние вкладки**: Только "💬 Поддержка"
- **Левое меню**: Поддержка, Заказы, Настройки
- **Дашборд**: SupportDashboard (тикеты, обращения)

#### 👤 **Партнёр**
- **Верхние вкладки**: Только "👤 Партнёр"
- **Левое меню**: Партнёр, Заказы, Настройки
- **Дашборд**: PartnerDashboard (личный кабинет партнёра)

## 🔍 Режим инспекции (только для Owner)

### Как включить
1. Откройте меню переключения ролей
2. В нижней части меню найдите "Инспекция доступов"
3. Переключите тумблер в положение ON

### Что это даёт
- Видны **все** разделы в левом меню
- Недоступные разделы помечены замочком 🔒
- Клик на недоступный раздел не работает
- Полезно для проверки прав доступа

### Пример использования
```
1. Включите режим инспекции
2. Переключитесь на роль "Склад"
3. Вы увидите все разделы, но:
   - "Администрирование" 🔒
   - "Финансы" 🔒
   - "Маркетинг" 🔒
   - "Поддержка" 🔒
   - "Партнёр" 🔒
   - "Тестирование" 🔒
```

## 📋 Тестовый сценарий

### Сценарий 1: Работа менеджера склада
```
1. Переключитесь на "Склад"
2. Проверьте, что видите только:
   - Вкладку "📦 Склад" сверху
   - Разделы: Склад, Заказы, Настройки
3. Откройте "Заказы"
   - Должна открыться таблица заказов для склада
4. Попробуйте вручную перейти в "Финансы" через левое меню
   - Этого пункта не должно быть в меню
```

### Сценарий 2: Работа финансиста
```
1. Переключитесь на "Финансы"
2. Проверьте, что видите только:
   - Вкладку "💰 Финансы" сверху
   - Разделы: Финансы, Заказы, Аналитика, Настройки
3. Откройте "Заказы"
   - Должна открыться таблица заказов с фокусом на финансы
4. Откройте "Аналитика"
   - Должна быть доступна аналитика
```

### Сценарий 3: Полный доступ Owner
```
1. Убедитесь, что выбрана роль "Owner/SEO"
2. Проверьте, что видите:
   - Все 7 вкладок сверху
   - Все разделы в левом меню
3. Переключайтесь между модулями через верхние вкладки
4. Все должно работать без ограничений
```

## 🐛 Что проверить

### Автоматический редирект
- [ ] При смене роли автоматически открывается домашний дашборд роли
- [ ] При попытке доступа к запрещенному разделу показывается ошибка

### Модульные вкладки
- [ ] Owner видит все 7 вкладок
- [ ] Другие роли видят только свою вкладку
- [ ] Активная вкладка подсвечена синим

### Левое меню
- [ ] Показаны только доступные разделы
- [ ] Режим инспекции показывает все с замочками
- [ ] Клик на заблокированный раздел не работает

### Toast-уведомления
- [ ] "Режим изменён: [Роль]" при смене роли
- [ ] "Раздел недоступен для текущей роли" при попытке доступа

### Консольные логи
- [ ] `🔄 Role changing from X to Y`
- [ ] `🔀 Auto-redirecting to: Z`
- [ ] `📊 Rendering content for: {...}`
