# 💸 Система обработки выводов средств

## Описание
Полная система заявок на вывод средств с автоматической обработкой администратором, возвратом средств при отклонении и детальной статистикой.

## Архитектура

### Backend API

#### 1. Создание заявки на вывод (пользователи)
```
POST /make-server-05aa3c8a/withdraw
Headers:
  - X-User-Id: {userId}
  - Authorization: Bearer {publicAnonKey}

Body:
{
  "amount": 5000,
  "method": "USDT",  // или "bank"
  "details": "TExample123..."  // адрес кошелька или номер карты
}

Response:
{
  "success": true,
  "withdrawal": {
    "id": "1702384920123",
    "userId": "012",
    "userEmail": "user@example.com",
    "userName": "Иван Петров",
    "amount": 5000,
    "method": "USDT",
    "details": "TExample123...",
    "status": "pending",
    "createdAt": "2024-12-11T12:00:00.000Z",
    "updatedAt": "2024-12-11T12:00:00.000Z"
  }
}
```

**Логика:**
- Проверяет баланс пользователя
- Списывает средства с баланса (резервирует)
- Создаёт заявку со статусом "pending"
- Сохраняет в KV по ключам:
  - `withdrawal:{withdrawalId}` - основная запись
  - `withdrawal:user:{userId}:{withdrawalId}` - для истории пользователя

#### 2. Получение всех заявок (админ)
```
GET /make-server-05aa3c8a/admin/withdrawals
Headers:
  - X-User-Id: {adminId}
  - Authorization: Bearer {publicAnonKey}

Response:
{
  "success": true,
  "withdrawals": [...]
}
```

#### 3. Обработка заявки (админ)
```
POST /make-server-05aa3c8a/admin/payout-action
Headers:
  - X-User-Id: {adminId}
  - Authorization: Bearer {publicAnonKey}

Body:
{
  "withdrawalId": "1702384920123",
  "action": "approve",  // или "reject"
  "note": "Выплачено на кошелёк 15.12.2024"  // опционально
}

Response:
{
  "success": true,
  "withdrawal": {...},
  "message": "Выплата подтверждена"
}
```

**Логика при approve:**
- Меняет статус на "completed"
- Сохраняет timestamp completedAt
- Сохраняет ID и имя администратора
- Сохраняет комментарий

**Логика при reject:**
- Меняет статус на "rejected"
- Возвращает средства на баланс пользователя
- Сохраняет timestamp rejectedAt
- Сохраняет ID и имя администратора
- Сохраняет комментарий

#### 4. Финансовая статистика (админ)
```
GET /make-server-05aa3c8a/admin/finance-stats

Response:
{
  "success": true,
  "stats": {
    "total_revenue": 150000,              // Оборот компании
    "users_balance_total": 45000,         // Сумма балансов всех партнёров
    "pending_payouts_sum": 15000,         // Сумма заявок к выплате
    "pending_payouts_count": 3,           // Количество заявок
    "net_profit": 105000,                 // Чистая прибыль
    "total_earnings_distributed": 45000,  // Всего начислено
    "completed_payouts_sum": 30000,       // Уже выплачено
    "total_orders": 25,
    "completed_orders": 20,
    "total_users": 15
  }
}
```

**Использование:**
```tsx
<AdminFinance currentUser={currentUser} />
```

#### 2. BalanceRu.tsx (Пользователи)
**Путь:** `/components/BalanceRu.tsx`

**Функции:**
- 💰 Отображение текущего баланса
- ➕ Форма создания заявки на вывод:
  - Выбор способа (USDT TRC-20 / Банковская карта)
  - Ввод суммы (минимум ₽1,000)
  - Ввод реквизитов
- 📜 История заявок пользователя
- 🎨 Цветовая индикация статусов:

**Для админов:**
- Также показывает все заявки в системе
- Возможность обработки заявок (legacy функция)

## Структура данных

### Withdrawal Object
```typescript
{
  id: string;                    // Уникальный ID (timestamp)
  userId: string;                // ID пользователя
  userEmail: string | null;      // Email пользователя
  userName: string;              // Имя пользователя
  amount: number;                // Сумма вывода
  method: string;                // "USDT" или "bank"
  details: string;               // Реквизиты
  status: string;                // "pending", "completed", "rejected"
  createdAt: string;             // ISO timestamp создания
  updatedAt: string;             // ISO timestamp последнего обновления
  
  // Опциональные поля (при обработке)
  note?: string;                 // Комментарий администратора
  completedAt?: string;          // Timestamp выплаты
  completedBy?: string;          // ID администратора
  rejectedAt?: string;           // Timestamp отклонения
  rejectedBy?: string;           // ID администратора
  processedByName?: string;      // Имя администратора
}
```

## Тестирование

### Сценарий 1: Пользователь создаёт заявку
1. Войдите как обычный пользователь
2. Перейдите в раздел "Баланс"
3. Убедитесь, что баланс >= ₽1,000
4. Нажмите "Создать заявку на вывод"
5. Выберите способ (USDT или Банковская карта)
6. Введите сумму (например: 5000)
7. Введите реквизиты (например: TExample123...)
8. Нажмите "Подтвердить вывод"
9. Проверьте, что:
   - Баланс уменьшился на сумму вывода
   - Заявка появилась в истории со статусом "Ожидание"

### Сценарий 2: Админ обрабатывает заявку (approve)
1. Войдите как администратор
2. Перейдите в раздел "Финансы" (или "Finance")
3. Увидите карточку "К выплате" с суммой pending заявок
4. Ниже - список заявок на выплату
5. Нажмите "Выплачено" на любой заявке
6. В диалоге введите комментарий (опционально)
7. Нажмите "Подтвердить"
8. Проверьте, что:
   - Заявка исчезла из pending
   - Появилась в истории операций со статусом "Выплачено"
   - Сумма "К выплате" уменьшилась

### Сценарий 3: Админ отклоняет заявку (reject)
1. Войдите как администратор
2. Перейдите в раздел "Финансы"
3. Нажмите "Вернуть" на любой pending заявке
4. Введите причину отклонения (опционально)
5. Нажмите "Отклонить"
6. Проверьте, что:
   - Заявка исчезла из pending
   - Появилась в истории со статусом "Отклонено"
   - Средства вернулись на баланс пользователя

### Сценарий 4: Проверка финансовой статистики
1. Войдите как администратор
2. Перейдите в раздел "Финансы"
3. Проверьте KPI карточки:
   - **Оборот компании**: сумма всех completed заказов
   - **Баланс партнёров**: сумма балансов всех пользователей
   - **К выплате**: сумма pending заявок (должна быть красной, если > 0)
   - **Чистая прибыль**: оборот минус начисления

## Проблемы и решения

### ❌ Проблема: withdrawal.id содержал префикс "withdrawal:"
**Было:**
```js
const withdrawalId = `withdrawal:${Date.now()}`;
await kv.set(withdrawalId, withdrawal);  // "withdrawal:123"
```

**Решение:**
```js
const withdrawalId = `${Date.now()}`;  // "123"
await kv.set(`withdrawal:${withdrawalId}`, withdrawal);  // "withdrawal:123"
```

Префикс теперь только в ключе, а не в ID объекта.
