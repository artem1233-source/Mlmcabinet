# Обновление меню дашборда

## Дата: 28 декабря 2025

## Изменения

### Убрана вкладка "Дашборд" для CEO/админов

**Файл:** `/components/SidebarRu.tsx`

**Изменение:**
- Вкладка "Дашборд" теперь отображается **только для обычных пользователей**
- CEO и админы не видят пункт "Дашборд" в боковом меню (у них есть Mission Control)
- Mission Control остаётся только для CEO

### Логика работы

#### Для обычных пользователей:
1. ✅ При входе показывается пользовательский дашборд (activeSection = 'дашборд')
2. ✅ В боковом меню ЕСТЬ пункт "Дашборд"
3. ✅ Могут переключаться между дашбордом и другими разделами
4. ✅ Доступны все стандартные разделы партнёра

#### Для CEO:
1. ✅ При входе показывается Mission Control
2. ✅ В меню НЕТ пункта "Дашборд"
3. ✅ Есть вкладка "Mission Control" с режимами просмотра
4. ✅ Имеют доступ ко всем функциям управления

#### Для админов (не CEO):
1. ✅ В меню НЕТ пункта "Дашборд"
2. ✅ Доступны административные функции
3. ✅ Видят Финансы, Пользователи, Админ-панель
