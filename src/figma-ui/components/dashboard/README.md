# 📊 Dashboard UI Components

Чистые UI компоненты для дашбордов Mission Control.

## Компоненты:

### CEOMissionControlView
**Файл:** `CEOMissionControlView.tsx`  
**Описание:** UI для CEO дашборда  
**Container:** `/src/containers/dashboard/CEOMissionControlContainer.tsx` (в Replit)

### AdminOpsDashboardView
**Файл:** `AdminOpsDashboardView.tsx`  
**Описание:** UI для Admin Operations дашборда  
**Container:** `/src/containers/dashboard/AdminOpsDashboardContainer.tsx` (в Replit)

### FinanceDashboardView
**Файл:** `FinanceDashboardView.tsx`  
**Описание:** UI для Finance дашборда  
**Container:** `/src/containers/dashboard/FinanceDashboardContainer.tsx` (в Replit)

## Общие UI компоненты (shared):

Эти компоненты используются в `/components/dashboard/`:
- `KPICard.tsx` - Карточка KPI
- `StatusLight.tsx` - Светофор статуса
- `ChartContainer.tsx` - Обёртка для графиков
- `ActionItem.tsx` - Карточка действия

Они уже чистые (без логики), поэтому их можно использовать как есть.
