🔥

1. Animated Action Block

Блок "Требует действий сегодня" с мигающими индикаторами, анимированными таймерами обратного отсчёта и градиентами для максимальной заметности критических товаров

3. Smart Order Recommendations

Кнопка "Рекомендуемый заказ: +XXX" вместо просто "Заказать" с умными расчётами запаса, визуальными акцентами и подробной информацией

📦 Версия 1: Оригинальный дизайн Current

✅ Блок "Требует действий сегодня"

Присутствует в верхней части с красной рамкой и таймерами. Градиент from-red-50 to-orange-50.

✅ KPI разделены на 2 уровня

Первичные (4xl шрифт, 4 карточки) и вторичные (2xl шрифт, 3 компактные карточки).

✅ Переключатель режимов в Burn Rate

3 режима: Расход / Тренд / Аномалии с подсветкой аномальных точек.

📝 Inventory List — стандартная кнопка

Кнопка "Заказать" с иконкой ArrowUpRight. Показывает рекомендуемое количество отдельно.

🚀 Версия 2: Action-first дизайн New
⭐ ОТЛИЧИЕ #1

🔥 Animated Action Block

Изменения:
• Анимированные градиенты (from-red-50 via-orange-50 to-yellow-50)
• Пульсирующий фон с animate-pulse
• Иконки с анимацией (Flame + Bell с animate-bounce)
• Таймеры с вращением (Timer с animate-spin 3s)
• Увеличенные размеры шрифтов (до 5xl для таймера)
• Кнопки с градиентами и animate-pulse

⭐ ОТЛИЧИЕ #2

📊 Extreme KPI Hierarchy

Изменения:
• Первичные KPI: текст 6xl (вместо 4xl), градиентные карточки
• Иконки увеличены до 10x10 (вместо 6x6)
• Карточки с эффектом hover:scale-105
• Вторичные KPI: минималистичный дизайн, bg-gray-50/50
• Заголовки с анимированными точками
• Чёткое визуальное разделение между уровнями

⭐ ОТЛИЧИЕ #3

🎯 Smart Order Recommendations

Изменения:
• Блок рекомендаций с 3-х пиксельной рамкой border-3
• Градиентный фон (from-[#39B7FF]/10 via-cyan-50 to-blue-50)
• Увеличенный шрифт для количества (5xl вместо 3xl)
• Кнопка с текстом "Рекомендуемый заказ: +XXX" и градиентом
• Дополнительная кнопка "Изменить количество"
• Иконка в контейнере с фоном
