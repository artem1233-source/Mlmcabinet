## 🔍 Найденная проблема

### Корневая причина:
Система **ошибочно считала пользователя 001 администратором**, из-за чего он фильтровался из всех списков обычных пользователей.

### Техническая деталь:
В функции `isUserAdmin()` (файл `/supabase/functions/server/index.tsx`, строка 209) была проверка:

```typescript
const isFirstUser = user.id === '1' || user.id === '001';
```

Это приводило к тому, что пользователь с ID `'001'` считался администратором и исключался из:
- ✗ Endpoint `/admin/users/all` (для дерева)
- ✗ Endpoint `/admin/users-tree`
- ✗ Фронтенд-фильтров в компоненте `UsersManagementRuV2.tsx`

## 💡 Важные моменты

### 🎯 Пользователь 001 - это НЕ администратор!

Пользователь **001** - это **корневой партнёр** MLM-системы:
- Он должен быть обычным пользователем (`type: 'user'`)
- Он должен иметь `isAdmin: false`
- Он должен отображаться в списках обычных пользователей
- От него строится всё дерево команды
- Все остальные партнёры - его потомки

### 🔑 Кто является администраторами?

Администраторами считаются ТОЛЬКО:
- Пользователь с `id === '1'` (если есть)
- Пользователь с `id === 'ceo'`
- Пользователи с `email === 'admin@admin.com'`
- Пользователи с явным `isAdmin: true`
- Пользователи с `type: 'admin'` или `роль: 'admin'`

**НО НЕ** пользователь с `id === '001'`!
