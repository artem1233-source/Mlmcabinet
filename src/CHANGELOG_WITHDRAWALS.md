#### Эндпоинт создания заявки на вывод
**Строки:** 2722-2751

**Изменения:**
```diff
- const withdrawalId = `withdrawal:${Date.now()}`;  // ❌ Неправильный префикс
+ const withdrawalId = `${Date.now()}`;              // ✅ ID без префикса

+ userEmail: currentUser.email || null,              // Добавлен email
+ userName: `${currentUser.имя || ''} ${currentUser.фамилия || ''}`.trim(), // Добавлено имя
+ updatedAt: new Date().toISOString()                // Добавлен updatedAt

- await kv.set(withdrawalId, withdrawal);            // ❌ Неправильный ключ
+ await kv.set(`withdrawal:${withdrawalId}`, withdrawal); // ✅ Префикс в ключе

+ console.log(`💸 Withdrawal requested: ₽${amount} by ${currentUser.имя} (ID: ${withdrawalId})`);
```

**Причина:**
- Префикс "withdrawal:" должен быть только в ключе KV, а не в ID объекта

- Улучшено логирование для отладки

## 🔧 Технические детали

### Ключи в KV Store

**Заявка на вывод:**
```
withdrawal:{withdrawalId}                          // Основная запись
withdrawal:user:{userId}:{withdrawalId}            // История пользователя
```

**Пример:**
```
withdrawal:1702384920123
withdrawal:user:012:1702384920123
```

### Статусы заявок

```typescript
type WithdrawalStatus = 
  | 'pending'      // Ожидает обработки
  | 'completed'    // Выплачено
  | 'rejected'     // Отклонено
```

### Методы вывода

```typescript
type WithdrawalMethod = 
  | 'USDT'         // Криптовалюта USDT TRC-20
  | 'bank'         // Банковская карта
```

## 🐛 Исправленные баги

### Bug #1: Дублирование префикса "withdrawal:"
**Проблема:**
```js
// Было
const withdrawalId = `withdrawal:${Date.now()}`;  // "withdrawal:123"
await kv.set(withdrawalId, withdrawal);            // Ключ: "withdrawal:123"
await kv.set(`withdrawal:${withdrawalId}`, ...);   // Ключ: "withdrawal:withdrawal:123" ❌
```

**Решение:**
```js
// Стало
const withdrawalId = `${Date.now()}`;              // "123"
await kv.set(`withdrawal:${withdrawalId}`, ...);   // Ключ: "withdrawal:123" ✅
```

### Bug #2: Отсутствие информации о пользователе
**Проблема:**
- В объекте withdrawal не было email и имени пользователя
- Администратор видел только userId

**Решение:**
- Добавлены поля userEmail и userName при создании заявки
- Информация извлекается из currentUser

### Bug #3: Недостаточное логирование
**Проблема:**
- Сложно было отследить, почему заявка не обрабатывается
- Непонятно, на каком этапе происходит ошибка

**Решение:**
- Добавлено детальное логирование на всех этапах
- Логи с эмодзи для удобства поиска (💸, 🔍, ✅, ❌, 💰)
