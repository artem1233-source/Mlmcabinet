## 🔍 Суть проблемы

Пользователь **001** не отображался в списках и дереве команды, потому что система **ошибочно считала его администратором**.

### Техническая причина:
```typescript
// ❌ БЫЛО (неправильно):
const isFirstUser = user.id === '1' || user.id === '001';

// ✅ СТАЛО (правильно):
const isFirstUser = user.id === '1';
```

Функция `isUserAdmin()` проверяла `user.id === '001'` и помечала такого пользователя как администратора, из-за чего он фильтровался из всех списков.

## 💡 Важно понимать

### Пользователь 001 - это НЕ администратор!

**Пользователь 001** - это **корневой партнёр** MLM-системы:
- ✅ Обычный пользователь (`type: 'user'`)
- ✅ Флаг `isAdmin: false`
- ✅ Отображается в списках партнёров
- ✅ На вершине дерева команды
- ✅ Родитель всех остальных партнёров

### Кто является администраторами?

Администраторами считаются ТОЛЬКО:
- Пользователь с `id === '1'` (если есть)
- Пользователь с `id === 'ceo'`
- Пользователи с `email === 'admin@admin.com'`
- Пользователи с явным `isAdmin: true`
- Пользователи с `type: 'admin'` или `роль: 'admin'`

**НО НЕ** пользователь с `id === '001'`!
