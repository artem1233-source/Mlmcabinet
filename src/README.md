# H2touch - MLM Личный кабинет партнёра

Интерактивное веб-приложение для управления MLM-структурой продаж водородного порошка и оздоровительных продуктов.

## ✨ Возможности

- 🎯 **Дашборд** - статистика доходов и команды
- 👥 **Структура команды** - визуализация партнёрской сети (3 уровня)
- 📦 **Заказы** - управление заказами и комиссиями
- 💰 **Баланс** - вывод средств через USDT/банк
- 🛍️ **Каталог товаров** - продукты с ценами по уровням
- 📚 **Обучение** - материалы для партнёров
- 👤 **Профиль** - реферальные ссылки и настройки
- 🔐 **Админ-панель** - управление пользователями и выплатами
- 💸 **Система выводов** - автоматическая обработка заявок на выплату
- 💎 **Neobank Finance** - современный дизайн страницы финансов (NEW!)

## 🛠️ Технологии

- **Frontend:** React + TypeScript + Tailwind CSS
- **Backend:** Supabase Edge Functions (Deno + Hono)
- **Database:** Supabase KV Store
- **Auth:** Telegram Mini Apps
- **Deploy:** Vercel (Frontend) + Supabase (Backend)

## 💸 Система выводов средств

Полноценная система обработки заявок на вывод средств с автоматизацией:

### Для пользователей
- ✅ Создание заявок на вывод через USDT (TRC-20) или банковскую карту
- ✅ Минимальная сумма: ₽1,000
- ✅ Автоматическое резервирование средств
- ✅ История всех заявок с отслеживанием статусов

### Для администратора
- ✅ Просмотр всех pending заявок в одном месте
- ✅ Быстрая обработка: одобрение или отклонение в 2 клика
- ✅ Автоматический возврат средств при отклонении
- ✅ Детальная финансовая статистика

## 💎 Neobank Finance Dashboard

Современный редизайн страницы финансов в стиле профессиональных необанков (Revolut, N26, Wise).

### Что нового
- ✨ **Bento Grid Layout (3:1)** - удобное разделение на рабочие зоны
- 📊 **График Revenue vs Payouts** - наглядная визуализация маржинальности за 30 дней
- 🎯 **Action Center** - все заявки на вывод в sticky sidebar справа
- 💳 **KPI карточки с трендами** - Total Revenue, Net Profit, Pending Payouts
- 🔍 **Фильтры и поиск** - tabs для типов транзакций + live search
- ⚡ **Bulk операции** - кнопка "Оплатить все" для массового одобрения
- 🎨 **Профессиональный дизайн** - gradients, shadows, современная цветовая схема

### Переключение версий
В интерфейсе доступны 2 версии:
- **Классический** - простой список транзакций (AdminFinance.tsx)
- **💎 Neobank Style** - современный dashboard (AdminFinancePage.tsx) - по умолчанию
