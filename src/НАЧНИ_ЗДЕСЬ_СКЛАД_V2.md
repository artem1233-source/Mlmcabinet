## 🎯 3 главных отличия

### 1. 🟣 Animated Action Block
Блок "Требует действий сегодня" с мигающими индикаторами и анимациями

**Что изменилось:**
- Анимированный 3-цветный градиент фона
- Иконка Flame (вместо Zap) с пульсацией
- Добавлена Bell с анимацией bounce
- Вращающийся Timer (3s)
- Счётчики увеличены: text-3xl → text-5xl
- Кнопки с градиентами и пульсацией

### 2. 🟢 Extreme KPI Hierarchy
KPI разделены на 2 радикально разных уровня

**Что изменилось:**
- **Первичные:** текст увеличен text-4xl → text-6xl, градиентные карточки, иконки w-10
- **Вторичные:** текст уменьшен text-2xl → text-xl, приглушённый фон
- Первичные выглядят в **3 раза крупнее** вторичных!

### 3. 🟠 Smart Order Recommendations
Кнопка "Рекомендуемый заказ: +XXX" вместо просто "Заказать"

**Что изменилось:**
- Число увеличено: text-3xl → text-5xl
- Текст кнопки: "Заказать" → **"Рекомендуемый заказ: +300"**
- Добавлен подзаголовок "На основе burn rate..."
- Расчёт "= запас на X дней"
- Дополнительная кнопка "Изменить количество"
