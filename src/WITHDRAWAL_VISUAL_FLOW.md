## 📋 Общая схема

```
┌─────────────────────────────────────────────────────────────┐
│                    СИСТЕМА ВЫВОДОВ                          │
│                                                              │
│  Пользователь                    Администратор              │
│      ↓                                ↓                      │
│  💰 Баланс                      📊 Финансы                  │
│      ↓                                ↓                      │
│  "Создать заявку"            Список pending                 │
│      ↓                                ↓                      │
│  Форма вывода                 ✅ Выплачено                  │
│   • Сумма                      ❌ Вернуть                   │
│   • Метод                            ↓                      │
│   • Реквизиты                   Подтверждение               │
│      ↓                                ↓                      │
│  Подтвердить                    Выполнено!                  │
│      ↓                                                       │
│  Баланс -₽5000                                              │
│  Статус: 🟡 Ожидание                                        │
└─────────────────────────────────────────────────────────────┘
```

## 🔄 Lifecycle заявки

```
┌──────────────┐
│   Создание   │  Пользователь создаёт заявку
│   заявки     │  • Сумма >= ₽1,000
└──────┬───────┘  • Баланс достаточен
       │          • Реквизиты указаны
       ↓
┌──────────────┐
│   PENDING    │  Статус: 🟡 Ожидание
│   (ожидает)  │  • Средства зарезервированы
└──────┬───────┘  • Баланс уменьшен
       │
       ├─────────────────┐
       │                 │
       ↓                 ↓
┌──────────────┐  ┌──────────────┐
│  COMPLETED   │  │   REJECTED   │
│  (выплачено) │  │  (отклонено) │
└──────────────┘  └──────────────┘
   Статус: 🟢        Статус: 🔴
   • Деньги         • Деньги 
     выплачены        вернулись
   • Комментарий    • Комментарий
     админа           админа
```

## 📊 Финансовая статистика

### KPI Карточки
```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  💰 ОБОРОТ        👥 БАЛАНС      ⚠️  К ВЫПЛАТЕ        │
│  ₽150,000         ₽45,000        ₽15,000               │
│  ↗ 20 заказов     Долг           🔴 3 заявки          │
│                   партнёров      ТРЕБУЕТ ДЕЙСТВИЙ      │
│                                                         │
│  💵 ПРИБЫЛЬ                                            │
│  ₽105,000                                              │
│  ↗ Оборот - начисления                                 │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### Расчёт статистики
```
Оборот компании          = Σ(completed заказы)
Баланс партнёров         = Σ(балансы всех users)
К выплате                = Σ(pending withdrawals)
Начислено всего          = Σ(все earnings)
Чистая прибыль           = Оборот - Начислено
```

## 🔐 Безопасность

### Проверки на Backend
```
┌──────────────────────────────────────┐
│  Создание заявки                     │
│  ✓ Авторизация (verifyUser)          │
│  ✓ Баланс >= amount                  │
│  ✓ amount >= 1000                    │
│  ✓ details не пустые                 │
└──────────────────────────────────────┘

┌──────────────────────────────────────┐
│  Обработка заявки                    │
│  ✓ Авторизация (verifyUser)          │
│  ✓ Админ права (requireAdmin)        │
│  ✓ Заявка существует                 │
│  ✓ Статус = pending                  │
└──────────────────────────────────────┘
```

## 🎨 Цветовая схема

```
Основные цвета:
  #39B7FF  →  Главный (синий)
  #12C9B6  →  Акцент (бирюзовый)
  #F7FAFC  →  Фон (светло-серый)

Статусы:
  🟡 Pending    →  Жёлтый/оранжевый (#FB923C)
  🟢 Completed  →  Зелёный (#10B981)
  🔴 Rejected   →  Красный (#EF4444)

KPI:
  Оборот        →  Синий (#39B7FF)
  Баланс        →  Оранжевый (#FB923C)
  К выплате     →  Красный (#EF4444) если > 0
  Прибыль       →  Зелёный (#12C9B6)
```

## 📱 Responsive Design

```
Desktop (>1024px):
  KPI карточки    → 4 в ряд
  Кнопки текстом  → "Выплачено" / "Вернуть"

Tablet (768-1024px):
  KPI карточки    → 2 в ряд
  Кнопки текстом  → "Выплачено" / "Вернуть"

Mobile (<768px):
  KPI карточки    → 1 в столбец
  Кнопки иконками → ✅ / ❌
```
