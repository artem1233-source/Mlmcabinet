# 🎭 Руководство по переключению ролей

## Что было реализовано

Добавлена система переключения ролей в основном интерфейсе партнёрской платформы H₂.

### ✨ Основные возможности

#### 1️⃣ Dropdown "Режим" в TopBar

В верхней панели (TopBar) добавлен dropdown "Режим" со следующими ролями:

- **Owner / SuperAdmin** - полный доступ ко всем функциям
- **AdminOps** - операционное администрирование
- **Finance** - финансовый отдел
- **Warehouse** - управление складом
- **Marketing** - маркетинг
- **Support** - служба поддержки
- **Partner** - обычный партнёр

#### 2️⃣ Фильтрация меню по ролям

При выборе роли левое меню автоматически показывает только доступные для этой роли разделы:

**Owner/SuperAdmin:**
- Все разделы доступны

**AdminOps:**
- Дашборд, Пользователи, Заказы, Каталог, Обучение, Достижения, Уведомления, Профиль, Настройки

**Finance:**
- Дашборд, Заказы, Финансы, Уведомления, Профиль, Настройки

**Warehouse:**
- Дашборд, Заказы, Каталог, Уведомления, Профиль, Настройки

**Marketing:**
- Дашборд, Пользователи, Маркетинг, Уведомления, Профиль, Настройки

**Support:**
- Дашборд, Пользователи, Заказы, Уведомления, Профиль, Настройки

**Partner:**
- Дашборд, Структура, Заказы, Доходы, Баланс, Каталог, Маркетинг, Обучение, Достижения, Уведомления, Профиль, Настройки

#### 3️⃣ Режим "Инспекция доступов" для Owner

Для роли Owner/SuperAdmin доступен специальный переключатель "Инспекция доступов":

- **Выключен** (по умолчанию): показываются только доступные пункты меню
- **Включен**: показываются ВСЕ пункты меню, недоступные помечаются серым цветом и disabled
- При наведении на недоступный пункт появляется tooltip "Недоступно для роли {роль}"

## 📁 Созданные файлы

### `/contexts/RoleContext.tsx`
Контекст React для управления текущей ролью и режимом инспекции:

- `RoleProvider` - провайдер контекста
- `useRole()` - хук для доступа к контексту
- `rolePermissions` - маппинг прав доступа для каждой роли
- `hasAccess()` - функция проверки доступа к пункту меню
- `getRoleLabel()` - получение русского названия роли

## 🎨 UX/UI особенности

1. **Визуальная обратная связь:**
   - Текущая роль отображается в dropdown с синей точкой
   - Выбранная роль подсвечивается фоном
   - Недоступные пункты в режиме инспекции серые с opacity 50%

2. **Tooltip подсказки:**
   - При наведении на недоступный пункт показывается причина

3. **Адаптивность:**
   - На мобильных устройствах название роли скрывается, остаётся только иконка

## 🔒 Принципы безопасности

⚠️ **ВАЖНО:** Это UI-фильтрация для удобства навигации, НЕ система безопасности!

- Фильтрация работает только на уровне отображения меню
- Реальная проверка прав доступа должна быть на backend
- Переключение роли НЕ влияет на права доступа к API

## 🚀 Использование

После входа в систему:

1. В правом верхнем углу TopBar найдите dropdown "Режим"
2. Нажмите на него и выберите нужную роль
3. Левое меню автоматически обновится, показывая только доступные разделы
4. Для Owner: включите "Инспекция доступов" чтобы видеть все пункты меню с пометками
