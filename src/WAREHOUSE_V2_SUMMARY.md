### ОТЛИЧИЕ #1: Animated Action Block (Фиолетовая рамка)

**Блок "Требует действий сегодня"** стал намного заметнее:

```
V1 → V2:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Градиент       | 2 цвета              → 3 цвета + анимация
Иконка         | Zap (w-7)            → Flame (w-9) + градиент + pulse
Доп. иконка    | —                    → Bell с animate-bounce
Таймер         | Timer статичный      → Timer с rotate (3s)
Счётчик        | text-3xl             → text-5xl + animate-pulse
Кнопка         | solid bg             → gradient + pulse + увеличена
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**Визуальный маркер:** 🟣 Фиолетовая пунктирная рамка с бейджем

### ОТЛИЧИЕ #2: Extreme KPI Hierarchy (Зелёная рамка)

**KPI разделены на 2 РАДИКАЛЬНО разных уровня:**

```
ПЕРВИЧНЫЕ KPI (огромные):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Числа          | text-4xl             → text-6xl font-black
Иконки         | w-6 простые          → w-10 с градиентом
Карточки       | стандарт             → градиент + shadow-2xl
Рамка          | border #E6E9EE       → border-3 #39B7FF
Эффекты        | —                    → hover:scale-105
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ВТОРИЧНЫЕ KPI (компактные):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Числа          | text-2xl             → text-xl
Иконки         | w-5                  → w-4
Фон            | white                → gray-50/50
Размер         | p-4                  → p-3
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**Результат:** Первичные метрики выглядят в **3 раза крупнее** вторичных!

**Визуальный маркер:** 🟢 Зелёная пунктирная рамка с бейджем

### ОТЛИЧИЕ #3: Smart Order Recommendations (Оранжевая рамка)

**Блок рекомендаций превратился в умную систему:**

```
V1 → V2:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Число          | text-3xl             → text-5xl font-black
Градиент       | 2 цвета              → 3 цвета
Заголовок      | простой              → с иконкой в контейнере
Подзаголовок   | —                    → "На основе burn rate..."
Расчёт         | —                    → "= запас на X дней"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
КНОПКА:
Текст          | "Заказать"           → "Рекомендуемый заказ: +300"
Фон            | solid                → gradient
Размер         | стандарт             → text-base px-8 py-6
Доп. кнопка    | —                    → "Изменить количество"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**Ключевое изменение:** Кнопка теперь **содержит количество** в своём тексте!

**Визуальный маркер:** 🟠 Оранжевая пунктирная рамка с бейджем
